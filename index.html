Early Virtual Metrology for Plasma Etching

Can machine signals tell us how deeply a wafer will be etched before its process run finishes? I built a model that estimates the final wafer-average silicon etch depth using only sensor readings from the first two minutes of a roughly ten-minute Bosch etch.

Python · PandasTime-series featuresRidge regressionLot-held-out validation
Sensor window observed: 120 sTypical etch: ~598 s
The prediction is made after roughly 20% of the recorded etch; the wafer continues processing normally.

How much do early signals add?

Each score comes from holding out one entire lot at a time. Lower mean absolute error (MAE) means more accurate predictions of final wafer-average etch depth.

The early model reduced pooled MAE by about 32% relative to wafer order alone. Its error was 0.003 µm higher than the full-trace model on these same lots.

What I built

  1. Joined in-situ process logs to later wafer measurements; kept one labeled observation per wafer.
  2. Extracted early features from pressure, gas flow, RF reflected power, platen voltage, and helium pressure.
  3. Trained Ridge models with imputation and scaling inside each training fold; tested on a different lot each time.

Does it hold across lots?

Early sensor features helped on nine of ten held-out lots. Lot 2 was the exception; it performed worse than wafer order alone.

What this result means

This is an early estimate of the final wafer-average measurement, evaluated retrospectively on ten lots. It does not show that conditioning is complete, establish a safe etch stopping point, or demonstrate time or material savings. The 120-second window and feature choices were explored on these same lots, so performance needs checking on genuinely new lots.
Data: Sayyed et al., BOSCH plasma-etching dataset. Related work has also predicted etch depth from these process signals, including Gaussian-process virtual metrology and a full-run wafer-mean benchmark. This project examines how early a useful wafer-mean prediction can be made.
